## ERC-8421 devnet, chain 1337 (`deployments/1337/pool.json`)

The organizers' alt mempool devnet (RPC `https://altmempool.forshtat.com`). Its 60M block gas limit caps deployable code at about 37 KB, so the terminal verifier (59 KB) and `ShieldedPool` (50 KB) cannot be deployed there. The record pairs the real accounts and leanSPHINCS verifier with `DevnetSettle`, which checks pool and scope and records nullifiers but does not verify the proof.

|---|---|

| PQPaymaster (validation limit 95,000) | `0x0e65c1b8663d9915d8738c16f01d678331cfbe4b` |
| leanSPHINCS verifier | `0xcd99ad22dfe9cca16908a0a1551071e8ad82d114` |

The exit key (`exitPkSeed`, `exitPkRoot`) is the same as on chain 8141. `deployments/1337/genesis/` packages the full pool, with the real terminal verifier and `ShieldedPool`, as genesis accounts for the devnet's operators.

## Record format

Each pool record also holds the pool and scope identities (`poolId`, `scope`, eight field elements each) that every spend's first 16 fields must match. Load records with `loadPoolDeployment` and `loadAccountDeployment` from the [SDK](/sdk/pool).
