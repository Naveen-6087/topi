---
title: "topi-node"
description: "Run a mixnet node, create node keys, and write topologies."
---

```text
topi-node <COMMAND>

Commands:
  keygen    Create a node key and print its public key
  topology  Write a topology from four node keys and the hosts they run on
  run       Run one node
```

`topi-node --version` and `--help` work on every command.

## keygen

```text
topi-node keygen <KEY>
```

Writes a fresh X-Wing node key to `KEY` (the 32-byte seed, hex) and prints the 1,216-byte public key as hex.

## topology

```text
topi-node topology <OUT> --members <FILE> --keys <DIR> --hosts <GATEWAY> <MIX> <EXIT> <REPLY_RELAY>
```

| Argument | Meaning |
|---|---|
| `OUT` | Topology file to write |
| `--members` | File with one member commitment (hex) per line, from `topi-client register` |
| `--keys` | Directory holding `gateway.key`, `mix.key`, `exit.key` and `reply-relay.key` |
| `--hosts` | Four hosts, in role order: gateway, mix, exit, reply relay |

Nodes get their default ports (47101 to 47104); the rate limiter (47201) and reply store (47250) are placed at the gateway's host. See [Topology file format](/reference/topology).

## run

```text
topi-node run <ROLE> --topology <FILE> --key <FILE> [OPTIONS]
```

| Argument | Default | Meaning |
|---|---|---|
| `ROLE` | | `gateway`, `mix`, `exit` or `reply-relay` |
| `--topology` | | Topology file |
| `--key` | | This node's key file |
| `--bind` | `0.0.0.0` | Address to listen on |
| `--stats-port` | `47300` | Port serving this node's counters as JSON |
| `--metrics-port` | `47400` | Port serving Prometheus metrics over HTTP (every metric is listed in METRICS.md) |
| `--batch-ms` | `1500` | How long the mix collects each batch, in milliseconds |
| `--spend-queue` | `spend-queue` | Where the exit queues pool spends; also read from `TOPI_SPEND_QUEUE` |

The node listens on its port from the topology. A gateway also starts the rate limiter, the reply store and cover traffic. The process prints `<role> node running`, then one line per notable event: released batches, epoch tickets verified or refused, queued spends and rejections.

## Ports

| Port | Service |
|---|---|
| 47101 | Gateway node |
| 47102 | Mix node |
| 47103 | Exit node |
| 47104 | Reply relay node |
| 47201 | Rate limiter (gateway host) |
| 47250 | Reply store (gateway host) |
| 47300 | Stats (every node, configurable) |
