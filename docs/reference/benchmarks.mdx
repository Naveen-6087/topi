Measurements come from development runs on a 16-thread laptop (Intel Core i5-12500H) unless noted, and from transactions on chain 8141. Numbers vary with hardware and load.

## Mixnet

| Measurement | Value |
|---|---|
| Packet size | 8,192 bytes at every hop |
| Packet construction | about 0.4 ms |
| Processing per hop | about 0.18 ms |
| Spend of 1.3 MB | about 280 packets on one rate-limit token |
| Ping round trip, four AWS regions | about 3.8 to 10 s |
| 1.3 MB spend over a mobile uplink to the AWS exit | queued in about 68 to 78 s |

## Rate limiting (depth 16, L = 16)

| Measurement | Value |

## Proofs

## End to end

Two notes to a mined settle, run by the console's `D` with `EXIT_PROVER=aws`:

| Step | Time |
|---|---|
| Deposits, witnesses, client proofs, mixnet sends | about 85 to 90 s |
| Recursion on a warm AWS instance | about 151 s (210 to 332 s on a fresh instance) |
| Settle through the alt mempool, mined | about 20 s |
| Total | about 216 to 301 s |

With the recursion on a laptop the total is about 20 minutes. The AWS prover instance costs about 0.47 USD per hour (spot), and its setup takes about 6 minutes once per instance.
